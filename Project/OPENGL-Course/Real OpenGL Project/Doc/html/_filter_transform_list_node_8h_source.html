8// =====================================================================
9// FilterTransformListNode — Filter scatter transforms by spatial rules
10// =====================================================================
11//
12// Percentage-based height filtering:
13// Threshold is 0–100% of the terrain's actual height range.
14// 0% = lowest point, 100% = highest point.
15// Example: "Y < 40%" means "only in the bottom 40% of terrain height"
16//
17// Takes a Mesh input (carrying a TransformList from ScatterNode) and
18// filters the transforms based on configurable spatial conditions.
19// Outputs the same mesh data with the filtered TransformList.
20//
21// Sits between Scatter and Output in the graph:
22// SceneInput → Scatter → FilterTransforms → Output
23//
24// Supports chaining multiple filters in sequence:
25// Scatter → Filter(Y < 40%) → Filter(slope > 0.8) → Output
26//
