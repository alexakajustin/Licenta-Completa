15// Each decorator is responsible for populating a specific room type
16// with appropriate furniture, fixtures, and props as MeshData geometry.
17//
18// The decorator interface is intentionally minimal: given a room and
19// an RNG, append prop geometry into a per-material mesh bucket map.
20// =====================================================================
