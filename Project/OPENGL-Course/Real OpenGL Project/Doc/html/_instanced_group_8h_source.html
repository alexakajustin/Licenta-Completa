18// =====================================================================
19// InstancedGroup — GPU-Driven Instanced Rendering for Millions of Objects
20//
21// Architecture (v2 — 10M+ scale):
22// 1. Stores all instance transforms in a GPU-side SSBO (32 bytes each)
23// 2. Partitions instances into spatial chunks for CPU-side pre-culling
24// 3. Runs a compute shader for frustum + distance + LOD culling on GPU
25// 4. Issues multi-LOD glDrawElementsIndirect calls (zero CPU draw overhead)
26// 5. Dedicated shadow pass with instanced shadow vertex shader
27//
28// Usage:
29// auto* group = new InstancedGroup("grass_field");
30// group->Setup(mesh, transforms, material, texture, normalMap);
31// // Each frame:
32// group->CullAndDraw(cullShader, renderShader, proj, view, camPos, ...);
33// group->CullAndDrawShadow(cullShader, shadowShader, lightVP, camPos, ...);
34// =====================================================================
