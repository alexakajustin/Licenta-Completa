12// ForEachNode — Places a mesh at each transform in a TransformList
13// =====================================================================
14//
15// This is a general-purpose loop node. It takes a list of transforms
16// (from Scatter or Filter) and a mesh, and produces a combined mesh
17// with the object placed at each transform position/rotation/scale.
18//
19// Unlike Scatter (which generates transforms), ForEach CONSUMES an
20// existing TransformList and applies arbitrary mesh data to it.
21//
